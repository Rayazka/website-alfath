# Interaktivitas Artikel Al-Fath Implementation Plan

> Execute inline using the executing-plans workflow. Rancangan disetujui pengguna pada percakapan implementasi W5.

**Goal:** Mengaktifkan pengelolaan artikel dummy pada halaman admin W4 menggunakan JavaScript murni dan jQuery.

**Architecture:** `article-data.js` menampung data awal dan fungsi domain murni; `script.js` menangani penyimpanan, render DOM, dan event jQuery. HTML/Tailwind W4 dipertahankan sebagai dasar. Data lintas halaman disimpan pada satu key localStorage.

**Tech Stack:** HTML, Tailwind CDN yang sudah ada, jQuery full 3.7.1, JavaScript, Node built-in test runner, Playwright untuk verifikasi browser.

## Global Constraints
- Tidak menambah halaman aplikasi baru atau backend.
- Setiap fungsi diberi komentar di atas deklarasinya, nama bermakna, maksimal 30 baris, maksimal empat parameter.
- Berkas JavaScript mendapat header @file, @brief, @author, @created, @todo.
- Semua teks pengguna dirender memakai textContent, bukan interpolasi HTML.
- Gambar hanya diperiksa dan disimpan nama berkasnya, bukan diunggah.
- Tidak melakukan commit, push, atau unggah video eksternal tanpa permintaan eksplisit.

## File map dan clean-code contract
| File | Tanggung jawab / header |
| --- | --- |
| `article-data.js` (baru) | @brief Process dummy articles with pure, testable functions; @todo none setelah selesai. Domain murni, tanpa DOM/storage. |
| `script.js` (baru) | @brief Connect article storage, DOM rendering, and jQuery interactions; @todo none setelah selesai. Pisahkan fungsi storage, render, dan event; tangani error storage secara terlihat. |
| `tests/article-data.test.js` (baru) | @brief Verify article filtering, pagination, validation, and persistence payloads; @todo none setelah selesai. Assertion berdasarkan perilaku, komentar pada setiap fungsi test. |
| `data.html`, `form-upload.html`, `dashboard.html` | Gunakan struktur W4; ganti dummy manual dengan container dinamis; hapus listener sidebar inline duplikat. Tambahkan identitas HTML dan label aksesibel. |
| `style/w5.css` (baru) | State validasi, whitespace detail, fokus, reduced motion; tidak mendesain ulang W4. |
| `README.md`, `docs/demo-w5.md` | Pemetaan rubrik, langkah uji, screenshot, cara memutar/merekam demo, status tautan video eksternal. |
